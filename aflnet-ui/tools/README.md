# 历史状态图重建

在仓库根目录运行：

```bash
python3 aflnet-ui/tools/rebuild_state_history.py --task history_mqtt_builtin_20260730
```

支持已停止的本地 MQTT、Modbus 任务。通过重复 `--task` 指定多条记录，
`--port 28885` 指定独立的本地回放端口。需要 C 编译器、Graphviz、后端依赖和对应的本地目标程序。

工具对已保存的队列、状态路径、崩溃和超时样本去重，每个样本使用新启动的目标进程回放。
全部响应交给当前 `aflnet.c` 解析器处理，同一任务共享状态编号映射。
状态路径沿用检测引擎的连续重复状态压缩规则。

结果保存在原输出目录的 `state-reanalysis/`：

- `responses/`：每个样本的服务端二进制响应。
- `samples.json`：输入摘要、回放结果、响应摘要及重建状态序列。
- `ipsm.dot`、`ipsm.svg`：重建状态图。
- `summary.json`：完成标记、解析器与目标摘要、重建统计。

原始状态图、统计、趋势和样本保持原样。页面和导出优先使用已完成的重建图及对应状态统计，
并标记为“历史样本回放重建”；执行次数等指标仍来自原实验。
原任务继续运行并产生新统计后，系统自动恢复使用运行中的状态图。

重建反映历史输入在当前目标上的响应，并非恢复原实验当时的响应。
已有的重建目录受到保护，重复运行会退出；中途失败的目录没有完成标记，不影响页面展示。
